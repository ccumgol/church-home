## 1. 프로젝트 개요 및 기술 스택

- **Static Site Generator:** Hugo v0.164.0+extended
- **Theme/Framework:** HugoBlox (TailwindCSS기반 모듈형 프레임워크)
- **Primary Color:** Warm Terracotta (`#D95D12`) — Admin 에서 변경 가능 (3-2-1 참고)
- **Base Background:** Warm Linen (`#faf8f5` / Dark: Deep Espresso `#17130f`)
- **팔레트 출처:** `data/themes/church-warm.yaml` (색은 여기서만 바꿉니다)
- **Hosting/CI:** GitHub Pages & GitHub Actions (`.github/workflows/deploy.yaml`)
- **Live URL:** `https://ccumgol.github.io/church-home/`

## 3-1. 첫 화면 배너 선택 (티커형 / 캐러셀형)

홈 화면 맨 위 배너는 **두 가지 중 하나를 골라 쓰는 구조**입니다. 교회 상황에 맞게 설정 한 줄만 바꾸면 됩니다.

| 값 | 배너 모습 | 어울리는 경우 |
|----|-----------|--------------|
| `ticker` | 배경 사진 한 장 + 최근소식이 한 줄씩 올라오는 티커 | 소식 전달이 중요하고, 화면이 차분하기를 바랄 때 |
| `carousel` | 여러 장이 6초마다 자동으로 넘어가는 슬라이드 | 행사 포스터나 여러 안내를 번갈아 보여 주고 싶을 때 |

### 바꾸는 방법 — Admin 페이지에서 (권장)

코드를 건드리지 않고 바꿀 수 있습니다.

1. `https://church-home.pages.dev/admin/` 접속 후 GitHub 로 로그인
2. 왼쪽 메뉴에서 **⚙️ 사이트 설정** → **첫 화면 배너**
3. **배너 종류** 를 고르고 **저장(Publish)**

| 항목 | 설명 |
|------|------|
| 배너 종류 | 티커형 / 캐러셀형 중 선택 |
| 캐러셀 전환 간격 (초) | 캐러셀형일 때 몇 초마다 넘어갈지. `0` 이면 자동 전환 안 함 |


저장하면 GitHub 에 커밋되고 Cloudflare Pages 가 사이트를 다시 만듭니다. **반영까지 1~2분** 걸립니다.

### 바꾸는 방법 — 파일로 직접

Admin 을 거치지 않으려면 `data/settings.yaml` 을 고쳐도 됩니다. Admin 이 저장하는 파일이 바로 이 파일입니다.

```yaml
hero_style: ticker            # 또는 carousel
carousel_interval_seconds: 6
```

> ⚠️ 이 파일은 Admin 에서 저장할 때 **파일 전체가 다시 쓰이므로 주석을 달아도 지워집니다.** 설명은 이 문서에 두세요.

어느 쪽으로 바꾸든, 선택하지 않은 배너는 **HTML 자체가 만들어지지 않고** 그쪽 전용 자바스크립트도 내려받지 않습니다. 두 배너가 같이 보이거나 쓰지 않는 스크립트가 도는 일이 없습니다.

잘못된 값(`hero_style: 뭔가이상한값`)을 넣으면 빌드가 깨지는 대신 경고를 남기고 티커형으로 처리합니다. `data/settings.yaml` 이 아예 없어도 티커형으로 동작합니다.

### 캐러셀 슬라이드 구성

캐러셀은 두 종류의 슬라이드를 이어 붙여 만듭니다.

1. **고정 슬라이드** — `content/_index.md` 의 `block: slider` → `content.slides` 에 적은 교회 소개용 슬라이드
2. **행사 슬라이드** — `content/event/` 의 글 중 `publish_to_home: true` 인 것이 최신순으로 자동 추가

고정 슬라이드 한 장은 이렇게 생겼습니다.

```yaml
- title: "예배 안내"
  content: "하나님을 향한 온전한 예배가 회복되는 곳"
  background:
    media: "vintage-floral-bg.png"   # assets/media/ 안의 파일명
  link:
    text: "예배 시간표 확인"
    url: "/about/#services"
    icon: "clock"                     # HugoBlox 기본 아이콘(heroicons) 이름
```

> `background.media` 를 비우면 따뜻한 테라코타 계열 기본 배경이 깔립니다.
> 아이콘은 heroicons 이름을 씁니다. 이 사이트에는 FontAwesome 이 없으므로 `fa-` 계열 이름은 표시되지 않습니다.

### 행사를 배너에 올리기

Admin(`/admin/`) → **📅 행사안내** 에서 글을 쓸 때

- **홈 화면 배너에 표시** 를 켜면 캐러셀에 추가됩니다.
- **행사 포스터** 를 올리면 배너에서 **오른쪽 단**에 포스터가, 왼쪽 단에 제목·설명·버튼이 놓입니다. 포스터가 없으면 글만 가운데 정렬됩니다.
- **간단 설명** 이 배너의 본문 문구로 쓰입니다.

### 높이 조절

높이는 디자인 값이라 Admin 이 아니라 `content/_index.md` 의 `block: slider` → `design` 에서 조절합니다. 모든 슬라이드가 같은 높이로 통일됩니다.

```yaml
design:
  slide_height: "72vh"          # PC 높이
  slide_height_mobile: "60vh"   # 모바일 높이
```

전환 속도는 위에서 설명한 대로 Admin 의 **캐러셀 전환 간격(초)** 에서 정합니다.

### 관련 파일

| 파일 | 역할 |
|------|------|
| `data/settings.yaml` | 첫 화면 배너 설정 (배너 종류, 전환 간격) |
| `data/heading.yaml` | 문서 제목 모양 설정 |
| `data/theme.yaml` | 강조 색상 설정 |
| `static/admin/config.yml` | Admin 의 "⚙️ 사이트 설정" 화면 정의 |
| `layouts/_partials/church/settings.html` | 설정값 해석 — data → params → 기본값 순으로 찾고, 잘못된 값은 걸러 냄 |
| `layouts/_partials/hbx/sections.html` | 설정값과 맞지 않는 배너 섹션을 걸러 냄 (`active: false` 도 여기서 처리) |
| `layouts/_partials/hbx/blocks/slider/block.html` | 캐러셀 마크업 |
| `assets/css/custom.css` (14번 섹션) | 캐러셀 디자인 |
| `static/js/church-carousel.js` | 캐러셀 동작 (자동 전환·스와이프·키보드) |
| `layouts/_partials/hooks/body-end/custom.html` | 선택된 배너의 스크립트만 로드 |

## 3-2. 페이지 제목 모양 선택 (배너형 / 말씀형 / 편집형)

메뉴를 눌러 들어가는 하위 페이지(교회소개, 말씀, 교회교육, 양육, 선교, 커뮤니티, 행사안내)의
제목 부분을 세 가지 모양 중에 고를 수 있습니다.

| 값 | 모양 | 인상 |
|----|------|------|
| `banner` (배너형) | 진한 테라코타 상자 안에 흰 제목 | 묵직하고 단정함 |
| `sermon` (말씀형) | 밝은 주황·앰버 상자 안에 흰 제목 | 밝고 활기참 (예전 '주일설교' 머리말) |
| `editorial` (편집형) | 작은 영문 안내 + 명조 제목 + 얇은 밑줄 | 차분하고 여백이 넉넉함 |

**바꾸는 곳:** Admin(`/admin/`) → **⚙️ 사이트 설정** → **문서 제목 모양**

(첫 화면 배너와 별개 화면입니다. 저장 파일도 `data/heading.yaml` 로 따로 있습니다)

**교회소개·말씀·교회교육·양육·선교·커뮤니티(교회소식·주보·포토앨범·양식자료실·정관)·행사안내**
— 메뉴로 들어가는 모든 문서에 한꺼번에 적용됩니다. 페이지마다 다르게 지정하지는 않습니다.

> 마크업은 `layouts/_partials/church/page_head.html` 한 곳에 모여 있고,
> `page/single.html`·`_default/list.html`·`_default/single.html`·`sermons/list.html`·`event/list.html`
> 이 모두 그 파셜을 부릅니다.
> 새 목록 페이지를 만들 때도 같은 파셜을 쓰면 모양이 자동으로 맞춰집니다.
>
> ```go-html-template
> {{ partial "church/page_head" (dict
>     "title" .Title
>     "eyebrow" "Events · 샘플교회 행사안내"
>     "meta" "총 12건"
> ) }}
> ```

## 3-2-1. 강조 색상 바꾸기

버튼·링크·아이콘·제목 배너 등 **사이트 전체의 강조색**을 Admin 에서 한 번에 바꿉니다.

**바꾸는 곳:** Admin(`/admin/`) → **⚙️ 사이트 설정** → **강조 색상**
(저장 파일: `data/theme.yaml`)

| 고를 수 있는 색 | 값 |
|----------------|-----|
| 따뜻한 테라코타 (기본) | `terracotta` |
| 앰버 골드 | `amber` |
| 올리브 그린 | `olive` |
| 딥 버건디 | `burgundy` |
| 미드나잇 블루 | `navy` |
| 로열 퍼플 | `purple` |
| 직접 지정 | `custom` + 아래 색상 칸 |

여섯 가지 기본 색은 따뜻한 리넨 배경과 어울리도록 미리 맞춰 둔 조합입니다.
'직접 지정'을 고르면 색상 칸에서 원하는 색을 뽑아 쓸 수 있습니다.

### 무엇이 함께 바뀌나

한 가지 색만 고르면 나머지는 자동으로 계산됩니다.

| 항목 | 처리 |
|------|------|
| 어두운 모드 색 | 배경에 묻히지 않도록 흰색 쪽으로 18% 밝게 |
| 보조색 (그라디언트 방향) | 강조색을 22% 어둡게 — 같은 계열 안에서 흘러 어떤 색을 골라도 안전 |
| 옅은 배경·테두리 (50~200) | 흰색과 섞어 자동 생성 |
| 진한 글자색 (600~950) | 검정과 섞어 자동 생성 |

바뀌는 곳: 버튼, 링크, 아이콘, 제목 배너, 설교 카드의 본문 배지와 재생 버튼,
태그 사이드바, 마무리 초대 카드, 푸터 링크 등 **강조색을 쓰는 모든 자리**.

배경색·글자색 같은 나머지 색은 바뀌지 않습니다.
그 값들은 `data/themes/church-warm.yaml` 에서 관리합니다.

### 잘못 넣어도 사이트는 안 깨집니다

- 모르는 색 이름 → 경고를 남기고 **기본 테라코타** 유지
- 색상 형식이 `#rrggbb` 가 아님 → 경고 후 기본색 유지
- `data/theme.yaml` 이 아예 없음 → 테마팩 기본색으로 동작

### 어떻게 동작하나 (개발자용)

```
data/theme.yaml
  → layouts/_partials/church/accent.html      색 계산 (밝은/어두운, 보조색)
    → layouts/_partials/hooks/head-end/custom.html
        프레임워크가 만든 --color-primary-* 를 head 끝에서 다시 선언
```

`head-end` 훅은 테마팩 `<style>` 보다 뒤에 놓이므로, 같은 선택자를 다시 써서
덮어씁니다. 테마팩 파일을 Admin 이 통째로 다시 쓰는 사고를 막기 위해
**강조색만 담는 작은 파일**을 따로 둔 구조입니다.

> ⚠️ 레이아웃에서 색을 쓸 때는 `orange-600` 처럼 고정된 색 이름 대신
> **`primary-600` / `secondary-600`** 을 쓰세요. 고정 색은 Admin 설정을 따라오지
> 않습니다. (이전에 남아 있던 215곳을 모두 `primary`/`secondary` 로 바꿨습니다)

## 3-3. 상단 메뉴 동작 방식

상위 메뉴(교회소개·말씀·교회교육·양육·선교·커뮤니티)는 **화면 크기에 따라 다르게** 동작합니다.

| 화면 | 상위 메뉴를 누르면 | 하위메뉴 여는 법 |
|------|-------------------|-----------------|
| PC (1024px 이상) | **첫 번째 하위 항목**으로 이동 | 마우스를 올리면 자동으로 펼쳐짐 |
| 모바일 | 이동하지 않고 **하위메뉴가 펼쳐짐** | 상위 메뉴를 탭 |

상위 메뉴의 주소는 `config/_default/menus.yaml` 에서 정하며, 관례상 **첫 번째 하위 항목과 같은 주소**를 씁니다.
하위 항목을 추가·삭제해 순서가 바뀌면 상위 메뉴 주소도 함께 맞춰 주세요.

### ⚠️ 앵커(`#`)는 반드시 소문자로

Hugo 가 링크를 만들 때 주소를 소문자로 바꾸기 때문에, 문서 안의 앵커도 소문자여야 합니다.

```html
<!-- 잘못됨: 메뉴 링크는 #tee 로 바뀌는데 앵커는 #TEE 라 이동 안 됨 -->
## <a id="TEE"></a>열린성경공부

<!-- 올바름 -->
## <a id="tee"></a>열린성경공부
```

> 실제로 '양육' 메뉴의 8개 항목이 이 문제로 전부 이동하지 않고 있었습니다. (이슈 28)

### 관련 파일

| 파일 | 역할 |
|------|------|
| `config/_default/menus.yaml` | 메뉴 구성과 주소 |
| `layouts/_partials/components/headers/navbar.html` | 메뉴 마크업 |
| `static/js/church-nav.js` | 화면 크기별 동작 분기, 바깥 클릭·Escape 로 닫기 |

## 3-4. Admin 으로 관리하는 게시판

글을 쓰고 고치는 일은 모두 Admin(`/admin/`)에서 할 수 있습니다.

| 메뉴 | 저장 위치 | 각 글이 눌렸을 때 |
|------|-----------|------------------|
| 📖 주일설교 | `content/sermons/` | 설교 상세 페이지 |

### 포토앨범 — 사진을 사이트에 올리지 않습니다

사진 수백 장을 사이트에 올리면 저장 용량과 속도에 부담이 됩니다.
그래서 포토앨범은 **Google 포토 링크만 모으는 방식**으로 만들었습니다.

1. Google 포토에서 앨범을 열고 **공유 → 링크 복사**
2. Admin → **🖼️ 포토앨범** → 새 앨범 만들기
3. 입력할 값

| 항목 | 설명 |
|------|------|
| 앨범 제목 | 예: 2026 여름 수련회 |
| 촬영일 | 목록 정렬 기준 |
| 대표 사진 (썸네일) | 목록에 보일 사진 한 장. Google 포토에서 한 장 내려받아 올리세요 |
| Google 포토 주소 | 1번에서 복사한 링크 |

목록에는 **썸네일 + 제목 + 날짜**만 나오고, 누르면 곧바로 Google 포토가 새 창으로 열립니다.
본문 내용은 보여 주지 않으며 개별 상세 페이지도 만들지 않습니다.

### 주보 — PDF 첨부

**📄 주보** 에서 '주보 파일(PDF)' 을 올리면 목록에서 표지를 누를 때 PDF 가 새 창으로 열립니다.
PDF 를 올리지 않으면 상세 페이지로 연결되므로, 링크가 끊기는 일은 없습니다.

> 업로드한 파일은 `assets/media/uploads/` 에 저장되고 Hugo 가 함께 내보냅니다.
> 사진은 가로 1600px 를 넘으면 자동으로 WebP 로 줄여 줍니다.

### `_index.md` 는 Admin 목록에 나오지 않습니다

각 게시판 폴더의 `_index.md` 는 목록 페이지의 안내문과 설정을 담고 있어서,
실수로 고치면 게시판이 통째로 망가질 수 있습니다. 그래서 글에만 붙는 숨은 값
(`board`)으로 걸러 Admin 목록에서 제외했습니다. 안내문을 바꾸려면 이 파일을 직접 여세요.

## 4. 주일설교 4단 동적 태그 레이아웃 & 필터링 연동 가이드

`content/sermons/` 디렉터리에 새로운 `.md` 파일을 추가하는 것만으로 4단 분할 레이아웃에 자동 축적되며, 우측 태그 클릭 시 즉시 해당 설교들만 필터링되어 노출됩니다.

### 4.1 필터링 동작 방식 (Client-side Data Filtering)
- **태그 클릭 시:** 우측 4번째 단의 `#마태복음`, `#요한복음`, `#담임목사` 등 흰색 태그 버튼을 클릭하면, 페이지 리로드 없이 즉시 해당 조건에 맞는 설교 카드들만 화면에 즉각적으로 필터링됩니다.
- **클릭한 태그 스타일:** 선택한 태그 버튼은 오렌지색 하이라이트 배경으로 전환되며, 상단에 `[#태그명 필터 검색 결과]` 상태바와 `[전체 설교 보기]` 리셋 버튼이 나타납니다.
- **토글 동작:** 활성화된 태그 버튼을 한 번 더 누르면 전체 보기 상태로 즉시 돌아옵니다.
